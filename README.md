# Infinite Stats / 无限加点

A Terraria-like infinite stat leveling system for Minecraft 1.20.1 Forge.

类似泰拉瑞亚的无限加点系统，适用于 Minecraft 1.20.1 Forge。

## 作者 / Author

佚名既无名

## 功能 / Features

- 56 个独特属性，分为 5 大类：攻击、防御、机动、功能、魔法
- 击杀怪物获得经验升级，获得属性点自由分配
- 开关类能力：飞行、夜视、隐身、物品磁铁、连锁挖掘、自动冶炼等
- 支持多人联机，属性数据同步

## 环境要求 / Requirements

- Minecraft 1.20.1
- Forge 47.3.0+
- Java 17

## 构建 / Build

```bash
./gradlew build
```

构建输出位于 `build/libs/`。
